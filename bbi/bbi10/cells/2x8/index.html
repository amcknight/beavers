Reproducing this cell

This cell's claims file is kept local and not posted, and the checker needs it. The checker is one Python file written from CHECKING.md, and with the claims file it reads the files above and takes the census file, which it does not read past depth 9.

python bbi9check.py <this cell's directory> --census census.tsv

The claims were made by our producer, version 0.5.0, as this cell's summary records, and the checker verifies them without it.

summary.json records the halter digest d5c00ae5aaa5d746 and the claims digest a185f213252875d9, for comparing a rerun with the same producer, bbi9 0.5.0.

amend.json records the amend digest f8845b1f7ea99eb6, for comparing an amendment with the same producer, bbi9 0.6.0.
