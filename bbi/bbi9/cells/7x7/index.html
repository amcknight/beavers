Parents are machines of eight instructions or fewer that our run could not settle. If one of them halts, its nine-instruction descendants can land in this cell, so the cell cannot close until they are settled.

Reproducing this cell

This cell's claims file is kept local and not posted, and the checker needs it. The checker is one Python file written from CHECKING.md, and with the claims file it reads the files above and the census.

python bbi9check.py <this cell's directory> --census census.tsv

The claims were made by our producer, version 0.3.0, as this cell's summary records, and the checker verifies them without it.

summary.json records the halter digest 2d1bd033d5c26858 and the claims digest da2e74a9b8ea3585, for comparing a rerun with the same producer, bbi9 0.3.0.

amend.json records the amend digest 56e1a7c63c1805fc, for comparing an amendment with the same producer, bbi9 0.5.0.
