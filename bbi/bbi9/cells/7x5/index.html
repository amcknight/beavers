Reproducing this cell

This cell's claims file is kept local and not posted, and the checker needs it. The checker is one Python file written from CHECKING.md, and with the claims file it reads the files above and the census.

python bbi9check.py <this cell's directory> --census census.tsv

The claims were made by our producer, version 0.4.0, as this cell's summary records, and the checker verifies them without it.

summary.json records the halter digest a170dbd926a394e9 and the claims digest 88bd4170a63ed54c, for comparing a rerun with the same producer, bbi9 0.4.0.

amend.json records the amend digest 4015286c218afa18, for comparing an amendment with the same producer, bbi9 0.5.0.
