Reproducing this cell

This cell's claims file is kept local and not posted, and the checker needs it. The checker is one Python file written from CHECKING.md, and with the claims file it reads the files above and the census.

python bbi9check.py <this cell's directory> --census census.tsv

The claims were made by our producer, version 0.2.0, as this cell's summary records, and the checker verifies them without it.

summary.json records the halter digest ed18dc1f8e544743 and the claims digest 4364a7e51a393e8e, for comparing a rerun with the same producer, bbi9 0.2.0.

amend.json records the amend digest 71abebb1af9dd940, for comparing an amendment with the same producer, bbi9 0.5.0.
