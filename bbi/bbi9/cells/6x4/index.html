Reproducing this cell

This cell's claims file is kept local and not posted, and the checker needs it. The checker is one Python file written from CHECKING.md, and with the claims file it reads the files above and the census.

python bbi9check.py <this cell's directory> --census census.tsv

The claims were made by our producer, version 0.5.0, as this cell's summary records, and the checker verifies them without it.

summary.json records the halter digest df39f1a78e853c2a and the claims digest 278a3d8deebfb09d, for comparing a rerun with the same producer, bbi9 0.5.0.

amend.json records the amend digest 08b8a21c52c8e93e, for comparing an amendment with the same producer, bbi9 0.6.0.

From the top of the repository, the import reads other people's lists and writes into another directory. Once its files are moved into the cell, the checker checks the import.

python -m experiments.bbi.bbi9.imports --bbi 9 6x4 --out experiments/bbi/bbi9/rerun/6x4
python experiments/bbi/bbi9/checker/bbi9check.py experiments/bbi/bbi9/cells/6x4 --import --census experiments/bbi/bbi9/census.tsv --lists experiments/bbi/lists.yaml
