Parents are machines of eight instructions or fewer that our run could not settle. If one of them halts, its nine-instruction descendants can land in this cell, so the cell cannot close until they are settled.

What no list decides is in BBi9_4x5_holdouts_after_lists_unofficial.txt and BBi9_4x5_parent_holdouts_after_lists_unofficial.txt.

A machine marked DECIDED_LIST may halt or never halt, and its list's maker knows which. A machine marked NONHALT_PROVEN never halts, by the registered proven value. Our own lists above are unchanged.

This rests on each list being its maker's whole list, as its entry in the registry states.

Reproducing this cell

This cell's claims file is kept local and not posted, and the checker needs it. The checker is one Python file written from CHECKING.md, and with the claims file it reads the files above and the census.

python bbi9check.py <this cell's directory> --census census.tsv

The claims were made by our producer, version 0.7.0, as this cell's summary records, and the checker verifies them without it.

summary.json records the halter digest ad14d49e2c4e3c4c and the claims digest b75c1727cb3a123c, for comparing a rerun with the same producer, bbi9 0.7.0.

From the top of the repository, the import reads other people's lists and writes into another directory. Once its files are moved into the cell, the checker checks the import.

python -m experiments.bbi.bbi9.imports --bbi 9 4x5 --out experiments/bbi/bbi9/rerun/4x5
python experiments/bbi/bbi9/checker/bbi9check.py experiments/bbi/bbi9/cells/4x5 --import --census experiments/bbi/bbi9/census.tsv --lists experiments/bbi/lists.yaml
