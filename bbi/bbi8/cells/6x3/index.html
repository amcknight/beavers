Parents are machines of seven instructions or fewer that our run could not settle. If one of them halts, its eight-instruction descendants can land in this cell, so the cell cannot close until they are settled.

Decided with other people's lists

Nick Drozd's BBi(8) holdout list of 2026-10-25 decides 145 of this cell's holdouts and no parent holdouts, leaving 16.

What no list decides is in BBi8_6x3_holdouts_after_lists_unofficial.txt and BBi8_6x3_parent_holdouts_after_lists_unofficial.txt.

A machine these lists decide may halt or never halt. Their makers know which. Our own lists above are unchanged.

This rests on each list being its maker's whole list, as its entry in the registry states.

The check read Nick Drozd's file by its SHA-256, aabde837dd73b5ef74f77bfd4f39737fe4d8755e5aead05d7e84141ad595b2c0, and the registry, experiments/bbi/lists.yaml.

Reproducing this cell

This cell's claims file is kept local and not posted, and the checker needs it. The checker is one Python file written from CHECKING.md, and with the claims file it reads the files above and the census.

python bbi9check.py <this cell's directory> --census census.tsv

The claims were made by our producer, version 0.3.0, as this cell's summary records, and the checker verifies them without it.

summary.json records the halter digest 6d8b4a7af3750681 and the claims digest 0c372e392c89eccd, for comparing a rerun with the same producer, bbi9 0.3.0.

amend.json records the amend digest c05bc5c9a58a906c, for comparing an amendment with the same producer, bbi9 0.5.0.

From the top of the repository, the import reads other people's lists and writes into another directory. Once its files are moved into the cell, the checker checks the import.

python -m experiments.bbi.bbi9.imports --bbi 8 6x3 --out experiments/bbi/bbi8/rerun/6x3
python experiments/bbi/bbi9/checker/bbi9check.py experiments/bbi/bbi8/cells/6x3 --import --census experiments/bbi/bbi9/census.tsv --lists experiments/bbi/lists.yaml
