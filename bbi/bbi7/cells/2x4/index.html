Decided with other people's lists

Terry Ligocki's BB(2,6) holdout list of 2025-10-06 decides 14 of this cell's holdouts, leaving none.

XnoobSpeakable's BB(3,4) holdout list of 2026-05-11 decides none of the holdouts that the lists above leave open.

What no list decides is in BBi7_2x4_holdouts_after_lists_unofficial.txt and BBi7_2x4_parent_holdouts_after_lists_unofficial.txt.

A machine these lists decide may halt or never halt. Their makers know which. Our own lists above are unchanged.

This rests on each list being its maker's whole list, as its entry in the registry states.

The check read Terry Ligocki's file by its SHA-256, 4d18230c9e6207aa6646858d0ff103998ea201b578b6628b0d0fd89c4529ae17 and XnoobSpeakable's file by its SHA-256, a06e234f51f9c58a7f5e906d8332643762a4af6164346950e2c70fa6ecf852cf, and the registry, experiments/bbi/lists.yaml.

Reproducing this cell

Anyone can check this cell without trusting us. The checker is one Python file written from CHECKING.md, and it reads the files above and the census.

python bbi9check.py <this cell's directory> --census census.tsv

The claims were made by our producer, version 0.3.0, as this cell's summary records, and the checker verifies them without it, and --amend checks the amendment.

summary.json records the halter digest 709c86919cf37ca0 and the claims digest 4a5e057e1b6777ed, for comparing a rerun with the same producer, bbi9 0.3.0.

amend.json records the amend digest e59f883260f01f69, for comparing an amendment with the same producer, bbi9 0.5.0.

From the top of the repository, the import reads other people's lists and writes into another directory. Once its files are moved into the cell, the checker checks the import.

python -m experiments.bbi.bbi9.imports --bbi 7 2x4 --out experiments/bbi/bbi7/rerun/2x4
python experiments/bbi/bbi9/checker/bbi9check.py experiments/bbi/bbi7/cells/2x4 --import --census experiments/bbi/bbi9/census.tsv --lists experiments/bbi/lists.yaml
