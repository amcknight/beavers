Reproducing this cell

Anyone can check this cell without trusting us. The checker is one Python file written from CHECKING.md, and it reads the files above and the census.

python bbi9check.py <this cell's directory> --census census.tsv

The claims were made by our producer, version 0.3.0, as this cell's summary records, and the checker verifies them without it, and --amend checks the amendment.
